The acceptance criterion — AC-105 (answers to FR-006)

Title

An oversized or wrong-type attachment is rejected with a locale-aware error and stores nothing

Criterion, as stored

**Given** a user attempts to attach a file to a topic <br> **When** the file exceeds the maximum allowed size (configurable, default 50 MB) or has a disallowed MIME type <br> **Then** the system rejects the upload with a clear locale-aware error naming the violated constraint; no partial file is stored and the topic is unchanged.

The acceptance criterion — AC-162 (answers to FR-006)

Title

**Given** a user attaching a file to a topic, from the submit page or from the topic's Attachments tab <br> **When** the file is larger than the configured maximum (configurable, default 100 MB) or has a disallowed MIME type <br> **Then** the upload is refused with a locale-aware message naming the violated constraint: a file over the maximum is refused in the browser before any bytes are sent, on BOTH surfaces; a file over the maximum that reaches the server within the maximum plus a 1 MiB multipart margin is refused by the validator with `FILE_TOO_LARGE`; no partial file is stored and the topic is unchanged. **And** a file at the maximum is accepted and stored: the server's own request-body limit for this endpoint follows the configured maximum plus the margin, so Kestrel's 30,000,000-byte default no longer applies to it (`DEF-166`), and a ~100 MB file completes through Kestrel, and through nginx and the object store in the E2E stack (`DEF-154`, `NFR-011`). **And** the meeting-recording ceiling (2 GB) is unchanged. ⚠ THIS CRITERION REPLACES `AC-105`, whose *"default 50 MB"* it changes (`DEC-190`, `SC-070`). **Verified by** unit tests of the options default and the validator; an API test that hosts the API on real Kestrel, stores a ~100 MB attachment and refuses one just over the maximum with `FILE_TOO_LARGE`; component tests of both upload surfaces refusing an over-maximum file in the browser with the translated message; a Playwright spec in the E2E stack uploading a ~100 MB file through nginx, Kestrel and MinIO; and a one-time measurement on uat, recorded with the build it ran against.
